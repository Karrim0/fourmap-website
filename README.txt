
# موقع فور ماب

موقع تعريفي – HTML / CSS / PHP

## طريقة التشغيل

1. يتم رفع مجلد المشروع `fourmap` داخل المسار التالي:

```
C:\xampp\htdocs\
```

2. تشغيل Apache من برنامج XAMPP.

3. فتح الموقع عبر المتصفح من خلال الرابط:

```
http://localhost/fourmap/
```

---

## هيكلة المشروع

```
fourmap/
│
├── assets/
│   ├── css/
│   ├── js/
│   └── images/
│
├── includes/
│   ├── header.php
│   └── footer.php
│
├── index.php
├── about.php
├── services.php
├── contact.php
├── 404.php
```

---

## مميزات المشروع

* تصميم متجاوب بالكامل (Responsive).
* تقسيم احترافي باستخدام header و footer قابلين لإعادة الاستخدام.
* إمكانية تعديل المحتوى بسهولة من خلال ملفات PHP.
* لا يحتاج إلى قاعدة بيانات.
* متوافق مع جميع المتصفحات الحديثة.
* كود منظم وسهل التطوير مستقبلاً.
